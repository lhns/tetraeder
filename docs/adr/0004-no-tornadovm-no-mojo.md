# 0004. No Java with TornadoVM, no Mojo for now

Status: Accepted

## Context

TornadoVM lags tuned kernels and lacks NCCL, attention and MoE kernels; JVM on every node; Mojo is young and not fully open.

## Decision

No Java with TornadoVM, no Mojo for now.

## Consequences

Revisit Mojo if it matures.
