# 0012. OpenTelemetry for metrics, traces and logs from the first commit

Status: Accepted

## Context

One data path for dashboards, alerts, detector and planner; works with your VictoriaMetrics and OTel stack.

## Decision

OpenTelemetry for metrics, traces and logs from the first commit; GenAI semantic conventions with their attribute names; tail sampling; SLO burn-rate alerts; nothing leaves the machine unless configured.

## Consequences

Overhead budgets per mode measured nightly on a GPU host.
